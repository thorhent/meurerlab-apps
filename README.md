# Repositório Flatpak - MeurerLab

Repositório gerado por `distribution/publicar.py` no projeto MeurerLab.

## Instalação

```bash
flatpak remote-add --if-not-exists --user meurerlab https://thorhent.github.io/meurerlab-apps/meurerlab.flatpakrepo
flatpak install --user meurerlab io.github.thorhent.Ollaprof
```
