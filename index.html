MeurerLab - repositório de aplicativos

Repositório Flatpak com os aplicativos clínicos do MeurerLab. Adicione o repositório uma única vez e receba as atualizações de todos os aplicativos com flatpak update.

Adicionar o repositório

flatpak remote-add --if-not-exists --user meurerlab https://thorhent.github.io/meurerlab-apps/meurerlab.flatpakrepo

Aplicativos

  • Ollaprof v0.10.26
    flatpak install --user meurerlab io.github.thorhent.Ollaprof
  • Docflow v1.8.26
    flatpak install --user meurerlab io.github.thorhent.Docflow
  • Clinical Ayudante v1.10.26
    flatpak install --user meurerlab io.github.thorhent.CA
  • Qiflow v1.10.26
    flatpak install --user meurerlab io.github.thorhent.Qiflow
  • Olladoc v1.10.26
    flatpak install --user meurerlab io.github.thorhent.Olladoc

Atualizar

flatpak update

Instalação com um clique: abra o .flatpakref do aplicativo.
